Nakama adalah platform AI agent untuk tim. Tujuannya: agent bekerja **bersama** tim, bukan menggantikan tim.

- Pengguna chat dengan agent di dashboard web (mirip ChatGPT).
- Setiap agent punya identitas, tools, skills, memori, dan channel sendiri.
- Satu server melayani banyak organisasi (multi-tenant).
- Bisa dipakai lewat Nakama Cloud (managed), Docker, atau Bun.
